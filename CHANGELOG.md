# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2024-06-09
- Added modern packaging via `pyproject.toml` with console script entry point.
- Implemented layered configuration (defaults, config files, env vars, CLI flags) with validation.
- Expanded CLI features: verbosity flags, dry-run mode, JSON output, and version reporting.
- Added typed configuration module, richer documentation, and updated architecture diagram.
- Enhanced tests covering configuration sources and error handling.
